## Receiver shape snapshot

States below come from [baseline.json](../../gitnexus/bench/receiver-resolution/baseline.json).
The [harness](../../gitnexus/bench/receiver-resolution/measure.mjs) defines each
spelling and its N/A reason. RESOLVES requires the exact expected declaration ID
and no same-named call to a different owner. WRONG-TARGET records incorrect edges.

| Shape                   | Recorded state | Expression or exclusion                 |
| ----------------------- | -------------- | --------------------------------------- |
| `plainChain`            | RESOLVES       | `svc.getUser().save();`                 |
| `plainDeepChain`        | RESOLVES       | `svc.getUser().address.save();`         |
| `optionalChain`         | RESOLVES       | `svc.getUser().address?.save();`        |
| `nonNullAssert`         | VISIBLE-GAP    | `svc.getUser().address!.save();`        |
| `awaitParen`            | RESOLVES       | `(await svc.getUserAsync()).save();`    |
| `explicitTypeArgs`      | VISIBLE-GAP    | `svc.getTyped<User>().save();`          |
| `indexElement`          | INVISIBLE-GAP  | `repos[0].save();`                      |
| `fieldReceiverCall`     | RESOLVES       | `this.repo.save();`                     |
| `decoratedReceiverBase` | N/A            | Dart `this` carries no type decoration. |
| `decoratedFieldType`    | RESOLVES       | `this.repo?.save();`                    |

Typed plain, deep, optional and field chains resolve. Before DART-04 was fixed, the awaited case was WRONG-TARGET: `getUserAsync()` declares `Future<User>`, but the call reached `Address.save` instead of `User.save` (the previous member-name-only gate had labeled it RESOLVES). The parenthesized head carried no receiver text, so the call was resolved receiver-less and the free-call tier bound `save` through the wildcard import's first-declared method. The emitter now gives the call its receiver text (so an untypable parenthesized head is a recorded `receiver-unresolved` drop, never a name guess) and a structural chain (`2|svc|cgetUserAsync|a`). The hoisted return binding of `getUserAsync` carries `Future<User>` whole — it used to arrive as a bare `Future` and be suppressed; only `Future`/`FutureOr` are re-joined, every other container keeps its bare spelling — so `svc.getUserAsync().save()` without an await types nothing, and the shared fold's `await` step unwraps the Future through the Dart `elementTypeOf` await route. [dart-awaited-receiver-owner.test.ts](../../gitnexus/test/integration/resolvers/dart-awaited-receiver-owner.test.ts) pins the exact `User.save` owner, the un-awaited and `Future<dynamic>` negatives, seven untypable parenthesized heads as recorded drops, and rejects the `Address.save` decoy — with a workspace `class Future<T>` present (DART-09), which an awaitable spelling must never bind to. The failing assertion spelling is `svc.getUser().address!.save()`; indexed access uses `List<User> repos`. The recorded statuses identify missing behavior but do not by themselves establish a root cause.

## Awaited inference and language versions

The five recall boundaries recorded during DART-04 review now have regression coverage:

1. A shared namespace prefix may name several libraries when exactly one exports the requested class. Distinct matching classes remain ambiguous.
2. A pattern field label is not a declaration or write to a same-named local.
3. Sibling lexical scopes infer independently. Writes to a captured outer binding still invalidate that binding; writes to a shadowing local do not.
4. An instance-method initializer follows a unique method on the receiver’s declared class or MRO. Untyped and shadowed receivers remain unresolved.
5. A prefixed factory with a qualified awaited yield resolves the qualifier in the producer’s scope, including through exports.

Tests: [inferred result scopes](../../gitnexus/test/integration/resolvers/dart-inferred-result-scopes.test.ts), [awaited receiver owners](../../gitnexus/test/integration/resolvers/dart-awaited-receiver-owner.test.ts), and [library exports](../../gitnexus/test/integration/resolvers/dart-library-exports.test.ts).

Wildcard handling follows the [Dart language-version policy](https://dart.dev/language/versioning): a leading `// @dart = major.minor` override wins; otherwise the nearest captured package’s SDK lower bound supplies the default. A file without a recognized lower bound uses the grammar’s Dart 3.7+ default. Patterns remain wildcards in earlier versions. Package boundaries with missing metadata do not inherit a parent package’s version.

Only legacy packages require cached source to be loaded again for version-sensitive extraction. Modern packages retain the durable ParsedFile path. [Cache replay tests](../../gitnexus/test/integration/review-followups-cache.test.ts) change only `pubspec.yaml` between 3.6 and 3.7 and verify the resulting edges without reparsing cached worker records.

## Scope-opener recall boundaries (DART-10)

Each of these trades a correct edge for a recorded drop; none produces a wrong owner.

1. **A parameter whose own scope declares its name again keeps no annotation.** The valid-Dart
   case was a collection `for` element, which bound into the enclosing scope (closed by DART-12):

   ```dart
   void collect(Address fs, List<Other> others) {
     final thunks = [for (final fs in others) () => fs.save()];
     fs.save();
   }
   ```

   Both `fs.save()` sites stopped at the untyped binder (`receiver-type-unresolved`): the inner one
   is an `Other`, which a surviving annotation would type as `Address.save`, a wrong edge, and the
   outer one lost its correct `Address.save` edge. `dartParameterRedeclared`
   (`gitnexus/src/core/ingestion/languages/dart/captures.ts`) counts declarations per scope, and a
   closure, local function, nested block, loop, case, catch body (DART-11) or collection `for` / `if`
   element (DART-12) that rebinds the name has a scope of its own. So the outer site now reaches
   `Address.save`, and only the inner one stops, at the element.

2. **An accessor body inherits the body-wide field-shadow mask.** Like a method body, an accessor body
   that binds a field's name anywhere masks that field for its bare reads:
   `Repo? get found { final repo = this.repo; if (repo == null) return null; return repo.find(); }`
   has no `Repo.find` edge (a recorded `receiver-owned-but-unbound`, the same as the method twin), and a
   comment-separated constructor with an initializing formal, `Box(this.cs) /* c */ { cs.save(); }`,
   behaves like its uncommented twin. Before DART-10 neither body had a scope to carry the mask.

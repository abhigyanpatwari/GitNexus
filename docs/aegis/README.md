# Aegis Workspace

This workspace stores design records, baseline snapshots, and implementation planning artifacts for repository changes that need durable review before code changes.

## Structure

- `specs/` contains product and architecture specifications.
- `baseline/` contains observed project snapshots used as evidence during planning.
- `adr/` may contain accepted architecture decision records when durable ownership or contract decisions are made.
- `work/` may contain temporary execution notes for long-running local work.

## Rule

Files here describe proposed or observed project state. They do not replace the repository source code, tests, or maintainer review.
